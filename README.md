# personal_rebuild

Rebuild of stevegotzler.net in Astro. All layout, style, and component code here is original;
nothing is copied from the themes or sites used as design references.

- `docs/rebuild-spec.md`: structure and content plan
- `src/config/site.ts`: site name, navigation labels, footer links
- `src/data/*.yaml`: the entries (books, design, writing and talks, past work)
- `src/pages/`: one file per page

Run locally: `npm run dev`, then open http://localhost:4321
