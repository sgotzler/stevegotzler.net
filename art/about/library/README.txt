ABOUT-PAGE MARK LIBRARY
Drawn October 2026 while working out the mark for the About page of stevegotzler.net.
All drawings are original line art.

marks/    15 full drawings of the worker placement mark (1200 x 1000)
icons/    41 single icons (560 x 560)
          board-*    game boards            play-*   analog play objects
          work-*     signs for work         digital-* computing objects (and a book)
          piece-*    the worker piece, pointer and resource used in the marks

Each folder has a dark/ and a light/ set, and every drawing is there twice:
  .svg  scales to any size; edit in any vector program or a text editor
  .png  for slides and documents

Colours   dark:  ink #EDE9E0 on #0D0C0A, accent #E2BDB8 (blush)
          light: ink #141210 on #F4F0E6, accent #8C4A57 (rose)

contact-sheet-dark.png / contact-sheet-light.png show everything at a glance.

To change a drawing or the colours, edit build.py and run:
  python3 build.py     (rewrites the SVGs)
  ./render.sh          (remakes the PNGs; needs Google Chrome)
The marks are built from the mark-a*.svg source files in the folder above this one.
